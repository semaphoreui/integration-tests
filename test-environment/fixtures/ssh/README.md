# SSH fixture key

The encrypted Ed25519 key pair is generated by `test-environment/profile up feature-ssh-local`
under the Git-ignored `build/test-fixtures/ssh` directory. It grants access exclusively to the
disposable profile container and must never be reused elsewhere.

Only the generated public key is mounted into the SSH container. Java tests send the private key
to the local Semaphore instance through the access-key API and verify that neither the key nor its
passphrase appears in API responses, task output, or HTTP diagnostics.
