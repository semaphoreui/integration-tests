# SSH fixture key

Two encrypted Ed25519 key pairs are generated by `test-environment/profile up feature-ssh-local`
under the Git-ignored `build/test-fixtures/ssh` directory. They grant access exclusively to the
disposable profile containers and must never be reused elsewhere.

Only the generated public keys are mounted into separate SSH containers. This lets the Java tests
prove that a repository fails with the old key, then succeeds after the same Semaphore access key
is rotated. The tests also verify that neither private key nor passphrase appears in API responses,
task output, or HTTP diagnostics.
